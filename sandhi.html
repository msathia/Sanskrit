सन्धिः

Rule-application notes for sound changes. The Maheshwara Sutras page keeps the sound groups and प्रत्याहार notation; this page keeps the places where those sound groups change in use.

Study Map

Sandhi notes are grouped by the kind of sound being changed. Vowel, visarga, and consonant sandhi each have their own rule area.

अच्सन्धिः

Vowel sandhi: one vowel meets another vowel.

अच् = vowels
अच् + अच् -> vowel sandhi rules
  • सवर्णदीर्घ, गुण, वृद्धि, यण्
  • यान्तवान्तसन्धिः
  • पूर्वरूप, पररूप, प्रकृतिभाव

विसर्गसन्धिः

Rules for final visarga before vowels and consonants.

ः + next sound
-> ओ, र्, लोपः, श्/ष्/स्, or special sound
  • अः + अ -> ओऽ
  • Detailed examples below
  • Keep separate from अच्सन्धिः

हल्सन्धिः

Consonant sandhi: a consonant meets another sound and changes by contact.

हल् = consonants
म् + consonant -> अनुस्वारसन्धिः
जश्त्व / पूर्वसवर्ण / ष्टुत्व -> consonant changes
  • अनुस्वारः: ं = ṃ
  • चन्द्रबिन्दुः: ँ marks optional nasalization
  • जश्त्व, पूर्वसवर्ण, and ष्टुत्व use the varga sound groups
  • Use the sound groups from the Sutras page

हल्सन्धिः

हल्सन्धिः means consonant sandhi. These rules show how a final consonant can change when it meets the next sound.

अनुस्वारः

अनुस्वारः = ं = ṃ
चन्द्रबिन्दुः = ँ
अं / इं / उं = aṃ / iṃ / uṃ
  • अनुस्वारः is the dot sign above a syllable.
  • In these notes, the ordinary sandhi form uses ं.
  • चन्द्रबिन्दुः is used only for the optional nasalized-semivowel notation below.

म् -> ं

word-final म् + non-nasal consonant
-> ं + non-nasal consonant
nasal consonants: ङ् ञ् ण् न् म्
  • फलम् + खादति -> फलं खादति
  • किम् + करोति -> किं करोति
  • ग्रामम् + गच्छति -> ग्रामं गच्छति
  • रामम् + वन्दे -> रामं वन्दे
  • अहम् + पठामि -> अहं पठामि

वर्गीयव्यञ्जनम्

ं + क्/ख्/ग्/घ् -> ङ् + क्/ख्/ग्/घ्
ं + च्/छ्/ज्/झ् -> ञ् + च्/छ्/ज्/झ्
ं + ट्/ठ्/ड्/ढ् -> ण् + ट्/ठ्/ड्/ढ्
ं + त्/थ्/द्/ध् -> न् + त्/थ्/द्/ध्
ं + प्/फ्/ब्/भ् -> म् + प्/फ्/ब्/भ्
  • Before a वर्गीयव्यञ्जनम्, अनुस्वारः can be shown as the fifth letter of that वर्गः.
  • शम् + करः -> शंकरः -> शङ्करः
  • ग्रामम् + गच्छति -> ग्रामं गच्छति; tightly joined: ग्रामङ्गच्छति

Optional Nasalized Semivowel

ं + य् -> य्यँ  (ỹy)
ं + व् -> व्वँ  (ṽv / ṽv)
ं + ल् -> ल्लँ  (l̃l)
  • चन्द्रबिन्दुः marks the optional nasalized semivowel.
  • Do not write these as iy, iv, or il; those look like extra vowel sounds.
  • सम् + वत्सरः -> संवत्सरः
  • Optional notation: संवत्सरः -> सव्वँत्सरः; saṃvatsaraḥ -> saṽvatsaraḥ

Joining And Splitting

फलम् + खादति -> फलं खादति
फलं खादति -> फलम् + खादति

शम् + करः -> शङ्करः
शङ्करः -> शम् + करः
  • First split the words.
  • Check the final sound of the first word and the first sound of the next word.
  • Then apply the local sound change.

पूर्वसवर्णसन्धिः

When a third varga letter is followed by ह्, replace the ह् with the fourth letter of that same varga.

द् + ह् -> द् + ध्

मरुत् + हरति
-> मरुद् + हरति     (जश्त्व)
-> मरुद्धरति        (पूर्वसवर्ण)

अकस्मात् + हेयम्
-> अकस्माद् + हेयम् (जश्त्व)
-> अकस्माद्धेयम्    (पूर्वसवर्ण)
  • जश्त्व first changes final त् to द् before the next sound.
  • Then द् + ह् becomes द् + ध्.
  • The same two-step pattern gives अकस्माद्धेयम्.

जश्त्वसन्धिः

At a word boundary, a final non-nasal varga consonant becomes the third letter of its own varga before a vowel or soft following sound.

क्/ख्/ग्/घ् -> ग्    च्/छ्/ज्/झ् -> ज्
ट्/ठ्/ड्/ढ् -> ड्    त्/थ्/द्/ध् -> द्
प्/फ्/ब्/भ् -> ब्

सुहृत् + आनयति -> सुहृदानयति

महत् + वनम्
त् + व् -> द् + व्
-> महद्वनम्

रामो महद्वनं प्राविशत्।
  • महत् = great; वनम् = forest.
  • महद्वनम् = a great forest.
  • सुहृत् + आनयति shows त् -> द् before the vowel आ.
  • Split: रामः + महत् + वनम् + प्राविशत्।
  • Meaning: “Rama entered the great forest.”

ष्टुत्वसन्धिः

When a dental sound meets a retroflex sound, the dental sound becomes the corresponding retroflex sound.

स् त् थ् द् ध् न्
-> ष् ट् ठ् ड् ढ् ण्

मनस् + षष्ठः -> मनष्षष्ठः
अस्मद् + डमरुः -> अस्मड्डमरुः
  • Look for a dental sound beside ष् or a ट-वर्गः sound.
  • मनस्: स् becomes ष् before ष्.
  • अस्मद्: द् becomes ड् before ड्.

विसर्गसन्धिः

विसर्गसन्धिः changes a final ः. Check both sides: the sound before ः, and the first sound of the next word.

अः -> ओ

अः + अ -> ओऽ
अः + soft consonant/semivowel -> ओ + soft consonant/semivowel
  • गजः + अगच्छत् -> गजोऽगच्छत्
  • बालः + रमते -> बालो रमते
  • नः + मित्रः -> नो मित्रः

विसर्गस्य लोपः

अः + vowel other than अ -> अ + vowel
आः + vowel or soft consonant/semivowel -> आ + vowel or soft consonant/semivowel
सः / एषः + sound other than अ -> स / एष + sound
  • रामः + इति -> राम इति
  • बालाः + आगच्छन्ति -> बाला आगच्छन्ति
  • बालाः + गच्छन्ति -> बाला गच्छन्ति
  • सः + पठति -> स पठति
  • एषः + गच्छति -> एष गच्छति

विसर्गस्य रत्वम्

not अः / not आः + soft consonant/semivowel -> र् + soft consonant/semivowel
not अः / not आः + vowel -> र् + vowel
  • हरिः + अवदत् -> हरिरवदत्
  • सिद्धिः + भवतु मे सदा -> सिद्धिर्भवतु मे सदा
  • गुरुः + ब्रह्मा -> गुरुर्ब्रह्मा
  • गुरुः + विष्णुः -> गुरुर्विष्णुः

श् / ष् / स् Replacements

ः + स् / त् / थ् -> स् + स् / त् / थ्
ः + श् / च् / छ् -> श् + श् / च् / छ्
ः + ष् / ट् / ठ् -> ष् + ष् / ट् / ठ्
  • नमः + ते -> नमस्ते
  • कः + चन -> कश्चन
  • रामः + षष्ठः -> रामष्षष्ठः

Special Visarga Sounds

ः + क् / ख् -> जिह्वामूलीयः
ः + प् / फ् -> उपध्मानीयः
  • रामः करोति: careful recitation uses जिह्वामूलीयः before क्
  • रामः पठति: careful recitation uses उपध्मानीयः before प्
  • These are often printed with the ordinary विसर्गः sign.

Reading Joined Forms

एकोऽश्वोऽवसत्
= एकः अश्वः अवसत्
= one horse lived
  • ऽ is अवग्रहः; it marks a missing short अ.
  • एकोऽश्वः keeps अश्वः hidden inside the joined form.

अच्सन्धिः

अच्सन्धिः means vowel sandhi. It happens when one vowel meets another vowel, usually at a word boundary or inside a compound.

सवर्णदीर्घसन्धिः

अष्टाध्यायी: ६.१.१०१ अकः सवर्णे दीर्घः 

अ + अ / आ -> आ
इ / ई + इ / ई -> ई
उ / ऊ + उ / ऊ -> ऊ
  • राम + अवतारः -> रामावतारः
  • गिरि + ईशः -> गिरीशः
  • गुरु + उपदेशः -> गुरूपदेशः

गुणसन्धिः

अष्टाध्यायी: ६.१.८७ आद्गुणः 

अ / आ + इ / ई -> ए
अ / आ + उ / ऊ -> ओ
अ / आ + ऋ / ॠ -> अर्
  • देव + इन्द्रः -> देवेन्द्रः
  • महा + ईश्वरः -> महेश्वरः
  • महा + उत्सवः -> महोत्सवः
  • महा + ऋषिः -> महर्षिः

वृद्धिसन्धिः

अष्टाध्यायी: ६.१.८८ वृद्धिरेचि 

अ / आ + ए / ऐ -> ऐ
अ / आ + ओ / औ -> औ
  • सदा + एव -> सदैव
  • तथा + एव -> तथैव
  • महा + ऐश्वर्यम् -> महैश्वर्यम्
  • महा + औषधम् -> महौषधम्

यण्सन्धिः

अष्टाध्यायी: ६.१.७७ इको यणचि 

इ / ई + vowel -> य् + vowel
उ / ऊ + vowel -> व् + vowel
ऋ / ॠ + vowel -> र् + vowel
ऌ + vowel -> ल् + vowel
  • यदि + अपि -> यद्यपि
  • इति + एवम् -> इत्येवम्
  • सु + आगतम् -> स्वागतम्
  • गुरु + आज्ञा -> गुर्वाज्ञा
  • पितृ + आदेशः -> पित्रादेशः

यान्तवान्तसन्धिः

अष्टाध्यायी: ६.१.७८ एचोऽयवायावः 

ए + vowel, except short अ -> अय् + vowel
ऐ + vowel -> आय् + vowel
ओ + vowel, except short अ -> अव् + vowel
औ + vowel -> आव् + vowel
  • द्वौ + अपि -> द्वावपि
  • सर्वे + आगताः -> सर्वयागताः
  • ए/ओ + short अ uses पूर्वरूपसन्धिः
  • Story words and meanings

Special Cases

अष्टाध्यायी: ६.१.१०९ एङः पदान्तादति, ६.१.८९ एत्येधत्यूठ्सु, १.१.११ ईदूदेद्द्विवचनं प्रगृह्यम्, ६.१.१२५ प्लुतप्रगृह्या अचि 

ए + short अ -> एऽ
ओ + short अ -> ओऽ
अ + ए -> ए

  • प्रकृतिभावः: द्वे + अपि -> द्वे अपि
